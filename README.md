## 🌌 Overview

**Nivedita | Digital Workspace** is a feature-rich, interactive web platform created to bring together personal branding, productivity, and e-commerce prototyping into a single seamless user experience. 

Designed with a dark cosmic aesthetic, this project serves as a comprehensive demonstration of front-end web development skills, including **DOM Manipulation**, **State Management**, **Browser Data Persistence (`localStorage`)**, and **Responsive Design**.


## ✨ Key Features

### 📁 1. Portfolio Workspace
A futuristic, space-themed developer portfolio highlighting my academic journey, technical expertise, and personal project universe.
- **Animated Hero Section:** Dynamic status animations (*"Building"*, *"Learning"*).
- **About & Education:** Details about my B.Tech CSE journey at UIT-RGPV (Autonomous), Bhopal.
- **Skills Dashboard:** Categorized showcase of programming languages (C++, Python, Java, JavaScript), web frameworks, and IoT/Hardware platforms (ESP32, Blynk, Arduino).
- **Project Showcase:** Highlights of major software and AI/Robotics projects:
  * *NiRaBot-X* — Humanoid AI Robot
  * *WAITLY* — Smart Queue Management
  * *SkyCast* — Weather Dashboard
  * *Chess Game with AI Integration*
- **Interactive Resume Modal:** Preview full resume with an embedded print/download PDF option directly from the UI.
- **Contact & Connect:** Direct social links to LinkedIn, GitHub, and email.

### 📝 2. Task Manager
A complete productivity app built directly into the workspace to help manage daily learning goals, tasks, and ideas efficiently.
- **Task Management:** Create, mark complete, and delete tasks with priority indicators (*High*, *Medium*, *Low*) and due dates.
- **Sorting & Filtering:** Filter tasks by status (*All*, *Pending*, *Completed*) and sort by priority, date, or recent additions.
- **Real-time Progress Tracker:** Dynamic progress bar showing task completion percentage.
- **Built-in Focus Timer:** Integrated 25-minute Pomodoro timer with start, reset, and `+5 minutes` extension options.
- **Quick Notes Section:** Dedicated space to jot down quick coding ideas and notes with instant search functionality.
- **Data Persistence:** Full integration with browser `localStorage` ensuring all tasks and notes remain saved after page reloads.

### 🛒 3. Shopping Store
A modern e-commerce storefront UI prototype designed for interactive online shopping simulation.
- **Product Discovery:** Product grid with category filters, dynamic price range sliders, and real-time search.
- **Interactive Shopping Cart:** Real-time cart counter, dynamic total calculation, and item management.
- **Quick View Modal:** In-depth view of product specifications and images without leaving the page.
- **Product Comparison Panel:** Side-by-side comparison of multiple items.
- **Favorites System:** Toggle favorite status on products for quick access.
- **Theme Customization:** Custom toggle options tailored for the shopping workspace view.

## 🛠️ Tech Stack & Tools

- **Frontend:** HTML5, Modern CSS3 (Flexbox, CSS Grid, Glassmorphism UI, Animations)
- **Scripting Language:** Vanilla JavaScript (ES6+)
- **State Management & Storage:** LocalStorage API, Asynchronous DOM Events
- **Development Environment:** VS Code, Live Server, Git, GitHub
- **Design Theme:** Dark Cosmic Aesthetic, Fully Responsive Layout

## ⚡ Installation & Local Setup
To run this project locally on your machine, follow these simple steps:

1. **Clone the Repository:**
```bash
git clone [https://github.com/niveditakirar4/Task4.git](https://github.com/niveditakirar4/Task4.git)
```

2. **Navigate into the Project Directory:**
```bash
cd Task4
```

3. **Open and Run:**
* Double-click `index.html` to open it in any modern web browser.
* *Alternatively*, open the folder in **VS Code** and click **Go Live** via the Live Server extension.


## 💡 Key Engineering Concepts Learned

1. **Vanilla JavaScript DOM Manipulation:** Efficiently updating dynamic content without using external UI frameworks.
2. **State Management:** Managing multiple app sections (Portfolio, Task Manager, Cart) cleanly within a single codebase.
3. **Client-Side Persistence:** Utilizing browser `localStorage` for asynchronous data management and auto-saving user actions.
4. **Responsive UI/UX:** Structuring CSS layouts that scale smoothly across smartphones, tablets, and desktop monitors.
